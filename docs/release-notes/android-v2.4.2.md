# YLSY Atlas Android 2.4.2

- Explicit system-bar insets: app canvas starts below status bar and ends above navigation bar, both bars match the app background.
- Drawer supports horizontal open/close swipes, outside tap and device back.
- Hidden platform scrollbars while preserving scrolling.
- Added Android WebView file chooser, document/backup export flow and popup routing for PDF and external links.
- Google setup now has account, folder and automatic backup steps. Removed manual sync; background sync runs automatically.
- Made Java/Python OAuth bridge arguments explicit and kept token encryption in Android Keystore.
