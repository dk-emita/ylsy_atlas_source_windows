# YLSY Atlas 2.3.6 — Onaylanan tek türbin simgesi

- **Kaynak resim:** `assets/ylsy_atlas_approved_turbine_source.png` (kullanıcının gönderdiği 320 × 320 PNG; tasarım değiştirilmedi).
- **Windows Gezgini/EXE:** `build.ps1` dosyası `assets/atlas-icon.ico` dosyasını `--icon` olarak kullanır.
- **Windows uygulama penceresi/görev çubuğu:** `run.py` aynı `assets/atlas-icon.ico` dosyasını `QIcon` ile yükler.
- **Sol menü:** aynı kaynağın 1024 px sürümü kullanılır ve uygulama açıkken 72 × 72 px gösterilir. Daraltılmış menüde 55 px görünür.
- **Web pencere simgesi:** aynı kaynağın 512 px sürümü.
- Veri tabanı, belgeler, kullanıcı ayarları ve diğer ekranların iş mantığı değiştirilmedi. İlk kurulumda kişisel örnek kayıtlar eklenmez.

## Windows'ta derleme

`powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`

İşlem bitince `dist\ylsy-atlas.exe` ve gerçek EXE kaynak simgesini gösteren `dist\build/reports/exe-icon-check.png` oluşur. Eğer Windows Gezgini eski önbelleği gösteriyorsa kontrol PNG'siyle karşılaştırın; eski görev çubuğu kısayolunu kaldırıp yeniden sabitleyin.

**Not:** Bu pakette hazır Windows EXE yoktur; Windows gerçek derlemesi bu Linux ortamında yapılamadı.
