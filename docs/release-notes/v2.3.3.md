# YLSY Atlas 2.3.3 – masaüstü ve simge düzeltmesi

- Sorunun kök nedeni: önceki `run.py`, `msedge.exe` veya `chrome.exe --app=... --user-data-dir=<geçici profil>` başlatıyordu; o pencerede görev çubuğu simgesini PyInstaller EXE'nin ICO kaynağı belirlemiyordu.
- `run.py` artık `PySide6.QtWebEngineWidgets.QWebEngineView` ile gerçek bir Windows masaüstü penceresi açar. `QIcon` hem uygulama hem pencereye atanır. Windows AppUserModelID `YLSY.Atlas.Desktop.2.3.3`.
- REBUS / NVİ gibi dış bağlantılar, uygulamanın mevcut `/api/open-external` işlevi üzerinden kullanıcının normal tarayıcısında açılır.
- DOCX, ZIP ve CSV indirme bağlantıları için yerel Qt dosya kaydetme iletişim kutusu eklenmiştir.
- Jet motoru görseli, büyük uygulama simgelerinde aynen korunmuştur; 16–64 px sürümler fanı öne çıkaracak şekilde yeniden örneklenmiştir.
- `build.ps1` kaynak ICO, sürüm ve uygulama dosyalarını paketlemeye devam eder; kurulum (`installer.iss`) de aynı simgeyi kullanır.
- İlk kurulum boş kalır, kullanıcı verileri `%LOCALAPPDATA%\YLSYAtlas2` altında kalır, mevcut kullanıcı verilerine dokunulmaz.

**Not:** Kaynak kodun API ve Python sözdizimi Linux'ta test edilebilir, ama Windows üzerinde Qt WebEngine/EXE görev çubuğu doğrulaması ayrıca yapılmalıdır. Bu ZIP hazır Windows EXE değildir.
