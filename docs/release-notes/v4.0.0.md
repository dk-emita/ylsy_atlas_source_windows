- Qt penceresinin ve sayfa motorunun açılmasını engelleyen uyumsuz ICU DLL dosyaları kurulum paketinden çıkarıldı. Windows'un ICU uygulaması kullanılır.
- Uygulama, pencere ve görev çubuğu ikonu onaylı `assets/icon.png` kaynağını kullanır. Windows ICO boyutları aynı görselden üretilir.
- Kurulum kısayolları ile çalışan uygulamanın AppUserModelID değerleri eşleştirildi.
- Derleme kontrolü gerçek HTML, CSS, JavaScript ve yerel API ile kontrol panelinin yüklenmesini doğrular; boş pencerenin açılmasını yeterli saymaz. Kontrol için kişisel kayıtlardan ayrı geçici bir çalışma alanı kullanılır.
- Kurulum çıktısı `dist/YLSY-Atlas-v4.0.0-Setup.exe` adını korur.

Google Drive kimlik doğrulama ve senkronizasyon işlevleri korunur. Herkese açık kaynak kopyada gerçek OAuth istemci kimliği veya sırrı bulunmaz; örnek yapılandırma alanları korunur.
