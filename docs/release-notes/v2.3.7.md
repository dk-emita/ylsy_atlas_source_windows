# YLSY Atlas 2.3.7 — Değişiklikler ve eksik kalanlar

- Gönderilen **60 sayfalık 1416'lı bursiyerler MEB ABD lisansüstü başvuru rehberi** kaynaklara gömüldü. İlk açılışta rehber PDF hazır.
- Açılışta Google Drive hesabını bağlama veya bağlamadan devam etme ekranı ve üst aramada profil simgesi.
- Google klasörü seçimi, `YLSY Atlas` alt klasörü oluşturma ve Drive API ile ZIP arşivi MD5 doğrulama kodları eklendi.
- Google Drive for Desktop yerel senkron klasörünü seçmek için Qt native klasör seçicisi eklendi.
- SQLite çalışma alanının ZIP yedeği ve yaklaşık dört saniyelik değişiklik izleme; çakışmalarda mevcut dosyayı ezmeme.
- **İptal edilen istek:** Sol menüdeki jet motoru ve “YLSY Atlas” yazısı aynen kaldı.
- **Doğrulanmadı / tamamlanmadı:** Gerçek Google hesabı OAuth oturumu (yayıncı client ID yok), Google Drive sunucusunda gerçek zamanlı senkron, yerel SQLite'i doğrulama sonrasında bütünüyle silme, Windows EXE ve görev çubuğu testi.
- Yalnızca kaynak paket, hazır EXE değil.
