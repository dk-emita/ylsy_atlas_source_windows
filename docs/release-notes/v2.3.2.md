# YLSY Atlas 2.3.2 — belge işlemleri ve simge düzeltmeleri

- **Belgelerim** başlığının sağında tek bir **neon kırmızı çöp kutusu** vardır. Yalnızca seçili belgeyi siler; silmeden önce belge adı gösterilerek onay istenir. Seçilmiş belge yoksa silme düğmesi devre dışıdır.
- Belge satırlarının yanındaki silme düğmeleri ve Belge Stüdyosu editöründeki **DOCX / Düzenle / Sil** grubunun **Sil** düğmesi kaldırıldı. DOCX ve Düzenle kaldı.
- Onaylanmış jet motoru görseli, Windows küçük boyutları için optimize edilmiş çok çözünürlüklü `.ico` dosyasına dönüştürüldü. Uygulamanın sol üst simgesi için ayrıca 512×512 yüksek çözünürlüklü görsel kullanılır; web istemcisinde önbellek karışması engellendi.
- Windows derleme betiği `build`, `dist` ve eski `.spec` dosyasını temizler; PyInstaller’a **mutlak ICO yolu** verir ve oluşan EXE'den simgeyi okuyup `dist/build/reports/exe-icon-check.png` olarak çıkartır.
- **Güncel paket kaynak koddur; Windows EXE bu Linux ortamında oluşturulup Windows üzerinde test edilmemiştir.** Kurulum için `build.ps1` çalıştırılmalıdır.
- Kullanıcı verilerinin depolama yolu değiştirilmedi. Uygulama güncellenmeden önce mevcut kullanıcı verilerini ZIP olarak yedekleyin.

## Windows kurulumu

ZIP'i yeni bir klasöre çıkarın; klasör içindeki `build.ps1` için:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

`dist/ylsy-atlas.exe` ve `dist/build/reports/exe-icon-check.png` dosyalarını karşılaştırın. Windows Gezgini eski simgeyi önbellekten gösterebilir; doğrulama PNG'si gerçek EXE kaynak simgesinden alınır. Görev çubuğundaki eski sabitlemeyi kaldırıp yeni EXE'yi sabitleyin. Eğer görüntü gerçek EXE simgesinde de eskiyse derleme dosyası ve kullanılan kaynak klasörünü kontrol edin.
