# YLSY Atlas 2.3.1 — düzeltme sürümü
- **Onaylanan jet motoru resmi** değiştirilmeden EXE ICO, uygulama simgesi ve 16–1024 px PNG çıktılarına işlendi.
- Sol menüdeki tüm sağ oklar tek dikey çizgide hizalandı.
- Belge Stüdyosu: belgelerin yanına görünür **Sil** düğmesi, editör başlığına **Sil** düğmesi eklendi. Silme öncesi onay istenir.
- Takvim: **Bugün** düğmesinin asgari genişliği ve duyarlı üst çubuk ölçüleri düzeltildi.
- MEB PDF: isim değiştirmeye gerek olmadan **PDF Seç / Değiştir** ile yerel dosya yükleme, dosya yoksa anlaşılır rehber ekranı; EXE yanında resources klasöründen PDF açma desteği.
- REBUS yazımı korundu.

**EXE notu:** Bu paket Windows'ta build.ps1 ile derlenir. Derlenmiş Windows EXE bu pakette yoktur. Önce kullanıcı yedeğini alınız. Varsayılan kişisel veri konumu değişmedi.
